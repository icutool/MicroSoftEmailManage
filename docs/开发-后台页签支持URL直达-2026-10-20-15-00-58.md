# 开发-后台页签支持 URL 直达

## 本次需求

后台的四个页签需要支持通过 URL 直接访问：

- 账号管理
- 邮件查看
- 日志
- 系统设置

例如访问 `/dashboard?tab=log` 时，页面打开后自动进入“日志”页签。

## URL 参数约定

| 页签 | 标准参数 | 兼容参数 |
| --- | --- | --- |
| 账号管理 | `?tab=accounts` | `?tab=account`、无参数或未知参数 |
| 邮件查看 | `?tab=mail` | `?tab=mails` |
| 日志 | `?tab=log` | `?tab=logs` |
| 系统设置 | `?tab=settings` | `?tab=setting` |

参数大小写不敏感。访问未知参数时回退到“账号管理”，并把地址规范化为 `?tab=accounts`。

## 实现说明

### 1. URL 与页签同步

在 `static/app.js` 中新增：

- `VIEW_TAB_VALUES`：内部视图名称与标准 URL 参数的映射。
- `TAB_VIEW_ALIASES`：URL 参数别名到内部视图名称的映射。
- `getViewFromUrl()`：读取并解析 `tab` 参数。
- `updateViewUrl()`：使用 `history.pushState` / `history.replaceState` 同步地址栏。

### 2. 统一页签激活流程

新增 `activateView()`，统一处理：

- 切换页签和页面标题。
- 同步 URL 参数。
- “账号管理 / 邮件查看”重新获取账号列表。
- “日志”加载刷新日志。
- “系统设置”加载代理配置。
- 恢复自动刷新计时器。

侧边栏点击和“查看该账号邮件”入口都改为复用该流程。

### 3. 刷新与前进后退

- 页面首次加载时按 URL 参数打开对应页签，并使用 `replaceState` 规范化地址。
- 点击页签时使用 `pushState` 写入历史记录。
- 监听 `popstate`，浏览器前进/后退时同步切换页签，不重复新增历史记录。

## 验证方式

1. 直接访问 `?tab=accounts`、`?tab=mail`、`?tab=log`、`?tab=settings`，确认分别进入对应页签。
2. 使用兼容参数 `account`、`mails`、`logs`、`setting`，确认也能正确进入，并规范化为标准参数。
3. 点击四个侧边栏页签，确认地址栏的 `tab` 参数随之变化。
4. 连续切换多个页签后点击浏览器后退/前进，确认页面页签与 URL 保持一致。
5. 刷新任意页签地址，确认仍停留在当前页签。

> 页面脚本没有版本号参数，验证前如仍看到旧行为，请使用 `Ctrl+F5` 强制刷新浏览器缓存。
