# 开发-邮件标签筛选支持排除模式

## 需求

邮件查看页（`mail-tag-filter`）原本只能"只展示选中标签"的账号，现在需要额外支持"排除选中标签"的账号。

## 变更内容

### 1. 页面结构 `templates/index.html`

在邮件查看页的筛选行中，标签下拉框后面新增一个筛选模式下拉框：

```html
<select id="mail-tag-filter-mode" class="input filter-select" title="切换标签筛选方式">
    <option value="include">包含标签</option>
    <option value="exclude">排除标签</option>
</select>
```

筛选行的容器类改为 `filter-row filter-row-tag-mode`，用于单独调整列宽。

### 2. 样式 `static/app.css`

新增 `.filter-row-tag-mode`，把该行改成三列（搜索框自适应 + 标签 120px + 模式 104px）。
移动端仍然沿用已有的 `.filter-row { grid-template-columns: 1fr; }` 单列堆叠。

### 3. 逻辑 `static/app.js`

- 新增常量 `TAG_FILTER_MODE_INCLUDE` / `TAG_FILTER_MODE_EXCLUDE`。
- `matchesTagFilter(account, selectedTag, mode)` 增加 `mode` 参数：
  - `include`：保持原有行为（选中具体标签 = 只看含该标签的账号；选中"无标签" = 只看没有任何标签的账号）。
  - `exclude`：选中具体标签 = 排除含该标签的账号；选中"无标签" = 排除所有带标签的账号（即只看无标签账号的补集）。
- `getFilteredAccounts(keyword, selectedTag, mode)` 透传 `mode`，账号管理页的调用不传该参数，行为不变。
- `renderAccounts()` 读取模式下拉框的值参与筛选，并在排除模式下于统计文案后追加"（已排除标签：xxx）"提示，避免用户误判筛选结果。
- 为 `mail-tag-filter-mode` 绑定 `change` 事件触发重新渲染。

## 影响范围

- 仅影响邮件查看页的账号筛选，账号管理页的标签筛选与导出逻辑保持不变。
- 排除模式与"无标签"选项组合时，语义为"排除无标签的账号"，即只显示有标签的账号。

## 验证方式

1. 打开邮件查看页，标签选择某个标签，模式选"包含标签"：只显示含该标签的账号（与改动前一致）。
2. 模式切换为"排除标签"：列表变为不含该标签的账号，统计文案后出现"（已排除标签：xxx）"。
3. 标签选"无标签" + 排除模式：只显示带标签的账号。
4. 标签选"全部标签"：模式切换不影响结果。
5. 移动端（宽度 < 980px）三列正常堆叠为单列。
